# Home Buys UK

The fourth site in the same playbook as Budget Buys UK, Pet Buys UK, and Baby Buys UK — separate repo, separate URL, same free hosting and same already-approved Amazon Associates account.

## One-time setup (only the account owner can do these — tied to identity)

1. Turn on GitHub Pages for this repo once pushed.
2. Add this site's URL to the Amazon Associates website list, same account as the other sites — no new application needed.

## What runs on its own

Same automation pattern as the other sites: a scheduled job works through `CONTENT_QUEUE.md`, researches real current UK products, writes a new guide, commits, and pushes. FAQPage structured data and internal linking are built in from the first post.

## Why this niche

Evergreen, high buyer intent (kitchen storage, laundry, organisation), and zero audience overlap with camping/gifts, pet products, or baby/toddler gear.
